펫 캘린더 v2.7.1은 WebView2 기반 v2.7.0의 후속 릴리즈입니다. 소스는 `webview-version` 브랜치에서 관리합니다.

## 일정 드래그 이동

- 달력의 일정 카드를 원하는 날짜로 끌어 이동할 수 있습니다. 일정 시간과 기간은 유지됩니다.
- 반복 일정은 이번 회차만 이동하거나 전체 반복 일정을 이동할 수 있습니다.
- 할 일을 달력으로 끌어 일정으로 전환할 수 있으며, 전환 직후 되돌리기를 지원합니다.

## 함께 포함된 개선

- 공휴일 표시와 펫 공휴일 인사
- 글씨 크기 선택: 작게 · 보통 · 크게
- 퀵투어에서 고양이 추가 및 도움말에서 투어 다시 보기
- 설치 필수 파일 검사와 퀵투어 이미지 빌드 보완

## 설치

`PetCalendar-Setup.exe`를 내려받아 기존 v2.7.0 설치 경로에 덮어 설치하세요. 기존 일정과 설정은 유지됩니다.

Windows x64, .NET Framework 4.8, Microsoft Edge WebView2 Runtime이 필요합니다.

`SHA256SUMS.txt`에서 설치 파일의 SHA-256 체크섬을 확인할 수 있습니다.

## 검증

Windows에서 일정·반복 모델, 일정 드래그, 할 일 전환·되돌리기와 저장 실패 시 보존, 퀵투어, 반복 일정 수정·재실행, 설치·업데이트·제거·재설치와 데이터 보존을 포함한 26개 테스트가 통과했습니다.
