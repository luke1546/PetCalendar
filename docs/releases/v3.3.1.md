펫 캘린더 v3.3.1입니다. **초록우산어린이 글꼴에서 일부 한글이 빈칸으로 보이던 문제**를 개선했습니다.

## 글꼴 개선

- 기존 초록우산어린이를 한글 11,172자를 지원하는 경량 확장 시험판으로 교체했습니다. ‘뷁·똠·힣’처럼 비어 있던 한글 8,822자를 원본 획 조합으로 채웠습니다.
- 기존에 그려져 있던 글자의 모양과 글자 폭은 유지했습니다. 공통 윤곽을 재사용해 전체 TTF 크기는 약 2.30MB입니다.
- 기존에 초록우산어린이를 선택했다면 업데이트 후 같은 설정으로 확장판을 사용합니다. 다른 글꼴을 사용 중이면 **설정 → 화면 → 글꼴 → 초록우산어린이**를 선택하세요.
- 이 글꼴은 산돌의 공식 확장판이 아닌 비공식 시험판이며, 새 글자 전체의 디자인을 수동 교정한 완성 서체는 아닙니다.

## 검증

- 앱에 포함된 폰트가 검증된 경량판과 일치하는지 SHA-256으로 확인했습니다.
- 앱의 실제 글꼴 로더와 Windows GDI에서 현대 한글 11,172자가 빈 윤곽 없이 표시되는지 검사했습니다.
- 3.3.0의 글꼴 선택값과 일정·설정을 유지하며 실행되는 것을 확인했습니다.

## 다운로드

- **`PetCalendar-Setup.exe`**: 기존 설치 위에 덮어 설치하면 일정과 설정을 유지합니다.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 설치판과 포터블의 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
