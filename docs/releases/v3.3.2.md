펫 캘린더 v3.3.2입니다. **호감도 이름표의 별·하트 이모지 변경**을 반영했습니다.

## 이름표

- 낯가림·친해지는 중·친구: **🌟**
- 단짝: **💚**
- 가족: **💖**

이름표 이모지는 앱에 포함된 컬러 이미지로 그려 선택한 글꼴에 관계없이 표시됩니다. 이름은 설정에서 선택한 글꼴을 그대로 사용하며, 호감도 단계가 오르면 이름표도 바로 갱신됩니다.

기존 펫의 이름·호감도·간식과 일정·설정은 유지됩니다. v3.3.1의 한글 확장 글꼴 개선도 포함됩니다.

## 다운로드

- **`PetCalendar-Setup.exe`**: 기존 설치 위에 덮어 설치하세요.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
