펫 캘린더 v3.3.3입니다. **장난감이 멀리까지 따라오고 여러 펫이 함께 쫓아오던 동작**을 수정했습니다.

## 장난감

- `token-usage-main`의 마우스 따라오기 로직을 기준으로, 펫 윤곽에서 **50px 이내의 가장 가까운 한 마리**만 선택합니다.
- 선택된 펫의 윤곽에서 **110px를 넘으면 다음 프레임에 장난감을 숨기고 추적을 해제**합니다. 위아래 거리와 대각선 거리도 확인합니다. 픽셀 기준에는 Windows 화면 배율을 반영합니다.
- 유지 범위 안에서는 같은 펫을 유지해 여러 펫 사이에서 대상이 계속 바뀌는 현상을 막습니다.
- 마우스 버튼을 누르거나 펫을 드래그·일시정지하거나 장난감을 끄면 추적을 해제합니다.
- 함께 놀고 있는 한 마리만 장난감 호감도를 받습니다. 다른 펫의 침대·이동 목표는 변경하지 않습니다.
- 창 위 발판에서도 마우스를 따라가며, 마우스에 도착하면 멈춥니다.

기존 일정·펫·호감도·설정과 v3.3.2의 컬러 이름표, 한글 확장 글꼴은 유지됩니다.
