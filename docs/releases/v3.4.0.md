펫 캘린더 v3.4.0입니다. 스티커 메모가 생겼고, 일정 분류를 새 일정 화면에서 바로 관리할 수 있습니다.

## 스티커 메모

- 위젯 위쪽의 **+** 버튼을 누르면 빈 스티커 메모가 위젯 옆에 열립니다.
- 메모는 자동 저장되고, 앱을 다시 켜도 같은 자리에 그대로 남아 있어요.
- 위쪽 막대를 끌어 옮기고, 가장자리를 끌어 크기를 바꿀 수 있습니다. 색은 노랑·분홍·초록·파랑 중에서 고를 수 있어요.

## 일정 분류

- 분류 추가는 이제 설정창이 아니라 **새 일정 화면의 ‘+ 분류’**에서 합니다.
- 분류 칩을 오른쪽 클릭하면 지울 수 있습니다. 업무·회의·마감·개인 같은 기본 분류도 **하나만 남기고 모두** 지울 수 있어요.
- 지운 분류의 일정은 남아 있는 첫 번째 분류로 옮겨집니다. 지운 기본 분류는 같은 이름으로 다시 추가하면 되살아나요.

## 화면

- 설정 → 화면에 **글씨 굵게**가 생겼습니다. 캘린더, 위젯, 펫 말풍선, 스티커 메모의 글씨가 모두 굵게 표시돼요.
- 바꾼 글꼴이 이제 **위젯**에도 적용됩니다.
- 일정 메모가 길어지면 입력칸에 스크롤이 생깁니다.

## 펫

- 마우스를 털실 공으로 바꾸는 장난감 놀이가 이제 **기본으로 꺼져** 있습니다. 펫 설정에서 다시 켤 수 있어요.
- 할 일 두 개를 한꺼번에 완료하면 펫 말풍선이 계속 바뀌며 깜빡이던 문제를 고쳤습니다.

## 다운로드

- **`PetCalendar-Setup.exe`**: 설치판입니다. 기존 설치 위에 덮어 설치하면 일정과 설정이 그대로 유지됩니다.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
