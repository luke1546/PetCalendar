펫 캘린더 v3.4.1입니다. 스티커 메모와 메모 칸을 더 편하게 다듬었습니다.

## 스티커 메모

- **×를 눌러도 내용이 남아 있어요.** 창만 닫히고 메모는 그대로 저장됩니다. 빈 메모는 닫으면 사라져요.
- 위젯의 **+**를 누르면 닫아 둔 메모 목록이 나와서 다시 열 수 있어요. 닫은 메모가 없으면 바로 새 메모가 열립니다.
- 메모를 완전히 지우려면 위쪽 막대의 **휴지통** 버튼을 누르세요.
- 메모가 길어지면 **마우스 휠**로 위아래로 스크롤할 수 있어요.

## 일정 메모

- 새 일정 화면의 메모 칸에서 **마우스 휠**이 동작합니다. 메모 끝에 닿으면 창 전체가 이어서 스크롤돼요.

## 화면

- 메모 칸과 스티커 메모의 스크롤바를 앱 테마와 같은 모양으로 바꿨습니다.
- 펫 이름 짓기 창의 회색 제목줄을 없애고 테마에 맞는 창으로 바꿨습니다.

## 다운로드

- **`PetCalendar-Setup.exe`**: 설치판입니다. 기존 설치 위에 덮어 설치하면 일정과 설정이 그대로 유지됩니다.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
