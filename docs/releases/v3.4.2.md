펫 캘린더 v3.4.2입니다. 달력 화면에서 바로 펫을 데려올 수 있습니다.

## 펫 추가하기

- 달력 창 오른쪽 위, **?** 버튼 옆에 **발바닥 버튼**이 생겼습니다.
- 누르면 고양이, 포메라니안, 레서판다, 카피바라, 다람쥐, 알파카, 코끼리, 랜덤 중에서 고를 수 있고, 고른 펫이 바로 바탕화면에 나타나요.
- 데스크톱 펫이 꺼져 있으면 자동으로 켠 뒤 데려옵니다.

## 다운로드

- **`PetCalendar-Setup.exe`**: 설치판입니다. 기존 설치 위에 덮어 설치하면 일정과 설정이 그대로 유지됩니다.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
