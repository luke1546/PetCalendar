펫 캘린더 v3.4.3입니다. 펫이 더 잘 보이고, 창 위에서 더 자연스럽게 움직입니다.

## 항상 맨 위에

- 펫, 이름표, 말풍선이 위젯이나 팝업처럼 **항상 위에 떠 있는 다른 창에 가려지지 않아요.**
- 말풍선이 여러 개 겹치면 **일정 말풍선이 일상 대화보다 위에** 보입니다. 일정 알림은 가장 위에 떠요.
- 전체 화면 게임이나 영상을 볼 때는 지금처럼 펫이 숨어서 화면을 가리지 않아요.

## 창 위의 펫

- 펫이 올라가 있는 창을 움직여도 펫이 순간이동하지 않아요.
- 창을 **천천히** 옮기면 펫도 함께 움직입니다.
- 창을 **빠르게 내리면** 펫이 떨어졌다가 창 위에 다시 착지하고, **빠르게 올리면** 발밑이 빠져서 아래로 떨어져요.

## 다운로드

- **`PetCalendar-Setup.exe`**: 설치판입니다. 기존 설치 위에 덮어 설치하면 일정과 설정이 그대로 유지됩니다.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
