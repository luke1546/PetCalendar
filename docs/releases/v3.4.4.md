펫 캘린더 v3.4.4입니다. 펫이 훨씬 부드럽고 빠릿빠릿하게 움직입니다.

## 더 부드러운 움직임

- 펫이 걷고, 떨어지고, 끌려갈 때 **초당 60프레임으로 고르게** 움직여요. 이전에는 실제로 초당 40프레임 정도라 조금씩 뚝뚝 끊겨 보였어요.
- 말풍선, 이름표, 털실 공도 펫과 같은 속도로 매끄럽게 따라와요.
- 마우스로 펫을 잡고 움직일 때 반응이 더 빨라졌어요.
- 120Hz, 165Hz 같은 고주사율 모니터에서도 펫이 일정한 속도로 움직여요.
- 펫이 쉬거나 잘 때는 프레임을 줄여서 CPU를 거의 쓰지 않아요.

## 다운로드

- **`PetCalendar-Setup.exe`**: 설치판입니다. 기존 설치 위에 덮어 설치하면 일정과 설정이 그대로 유지됩니다.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
