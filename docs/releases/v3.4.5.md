펫 캘린더 v3.4.5입니다. 캘린더가 더 부드럽고 빠르게 반응합니다.

## 부드러운 스크롤

- 마우스 휠로 스크롤하면 한 번에 툭 뛰지 않고 **미끄러지듯 부드럽게** 움직여요.
- 휠을 빠르게 여러 번 굴리면 그만큼 이어서 더 멀리 스크롤돼요.
- 달력 화면, 그날 일정과 할 일 목록, 검색 결과, 일정 창과 설정 같은 팝업, 바탕화면 위젯의 일정 목록에 모두 적용했어요.

## 더 빨리 열리는 일정 창

- 캘린더를 켠 뒤 **처음 일정 창을 열 때 기다리는 시간이 절반 넘게 줄었어요.**

## 다운로드

- **`PetCalendar-Setup.exe`**: 설치판입니다. 기존 설치 위에 덮어 설치하면 일정과 설정이 그대로 유지됩니다.
- **`PetCalendar-Portable.exe`**: 설치 없이 이 파일 하나로 실행됩니다.

Windows x64, .NET Framework 4.8이 필요합니다. 체크섬은 `SHA256SUMS.txt`에서 확인할 수 있습니다.
